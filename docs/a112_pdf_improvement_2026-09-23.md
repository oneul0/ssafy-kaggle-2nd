# A112 발표자료를 참고한 다음 실험 (2026-09-23)

## 확인된 사실

- 첨부 PDF의 Public LB는 0.95650에서 0.96723으로 상승했다. 문서에는 Qwen3.5-35B-A3B LoRA 단독 0.96365, 최종 블렌드 0.96723으로 적혀 있다. 여러 변경의 기여는 분리되지 않았다.
- PDF의 35B 실험은 BF16, 비양자화, 2 epoch, LR 5e-5, LoRA r16/alpha32/dropout 0.05, 언어 attention projection 대상이다. 로컬 RTX 5060 Ti 16GB에 동일한 비양자화 35B 학습을 그대로 적용할 수 없다.
- 현재 로컬 4B 두 모델은 BF16, 1 epoch, LR 1e-4, r16/alpha32로 학습했다. 답 한 글자 loss, 보기 셔플, 직접 로짓 비교는 이미 적용했다.
- 현 4모델 선택적 크롭은 고정 1,000개 홀드아웃 959/1000, Public 0.96187. 새로 학습한 두 4B의 보기 회전 0~3을 넣으면 같은 홀드아웃 965/1000(기준 대비 복구 6, 손실 0)이며, 현재 6,714개 test 추론이 진행 중이다. PDF는 자신의 option-order ensemble이 하락했다고 보고했으므로, 효과는 모델마다 다르다.

## 우선순위와 채택 기준

1. **진행 중인 회전 후보 완료.** 전체 test 확률과 6,714행 CSV를 검증한다. Kaggle Public 점수를 받아 0.96187과 비교한다. 그전에는 회전 TTA를 최종 개선으로 단정하지 않는다.
2. **4B 학습 길이와 학습률을 분리 실험.** GPU가 비면 Qwen3.5-4B를 우선 대상으로 현재 1 epoch·1e-4에서 이어 학습한 2 epoch 후보와, 초기 가중치에서 2 epoch·5e-5로 학습한 후보를 각각 만든다. 체크포인트는 train-fit 내부 개발 분할에서 고르고 고정 홀드아웃에서 한 번 비교한다. 단독 정확도보다 현재 앙상블의 복구/손실을 기준으로 채택한다. 다른 4B 모델로 확대는 첫 모델 결과를 본 뒤 결정한다.
3. **모델 불일치 라우팅.** 현재 네 모델과 새 회전 4B의 확률을 이용해 저신뢰·불일치 행만 다른 가중치를 적용한다. 문서의 35B:8B 블렌드 숫자를 그대로 복사하지 않는다. 임계값과 가중치는 train-fit 개발 분할에서 고정하고, 1,000개 홀드아웃에서 기존 965/1000 대비 복구/손실을 확인한다. 단일 홀드아웃의 작은 이득만을 위해 복잡한 규칙을 추가하지 않는다.
4. **오답 유형별 이미지 판독.** 앙상블 전체가 틀린 사례와 숫자·작은 글씨·위치 관계를 나누어 본다. OCR 또는 질문 대상 크롭은 해당 유형의 train-fit 개발 분할에서 먼저 평가한 뒤 고정 홀드아웃과 전체 test에 동일한 규칙을 적용한다.

## 자원과 규칙

- 35B BF16 가중치만 약 70GB 규모이므로 16GB 로컬 GPU에서 발표자료와 같은 조건의 학습은 계획하지 않는다. 대형 모델은 사용 가능한 연산 자원이 생기면 별도 실험으로 검토한다.
- 테스트 이미지를 보고 정답을 손으로 고치지 않는다. 외부 추론 API를 사용하지 않는다. 후보는 모델 확률, 코드, 고정 검증, 전체 6,714개 CSV로 재현한다.
