# 0.96187 이후 모델 개선 설계 (2026-09-23)

## 기준과 목표

- 현재 채택 후보: 4모델 앙상블 + 선택적 크롭. 홀드아웃 959/1,000, Public 0.96187.
- 목표 Public 0.98까지 1.813%p가 남았다. 홀드아웃에서도 980/1,000을 목표로 보면 현재보다 순증 21문항이 필요하다. 두 집합은 다르므로 이 수치는 계획 기준일 뿐이다.
- 현 후보의 홀드아웃 오답 41개 중 30개는 구성 모델 네 개 중 적어도 하나가 정답을 골랐다. 11개는 네 모델 모두 오답이다. 따라서 답을 선택하는 방식과 이미지 판독 능력을 각각 개선해야 한다.
- test 정답이나 Public 점수에 맞춰 행별 답을 고치지 않는다. 모든 후보는 고정된 추론 코드와 모델 확률에서 6,714행 전체를 만든다. 외부 추론 API를 사용하지 않는다.

## 1. 보기 순서 회전 추론을 먼저 재현

공유 저장소에는 Qwen3.5-4B LoRA와 Qwen3-VL-4B LoRA의 홀드아웃 회전 0~3 확률이 저장돼 있다. 두 모델의 네 회전 확률을 각각 평균하고, 기존 Qwen2.5-VL-7B 및 현재 선택적 크롭 8B와 결합하면 다음과 같다.

| 방식 | 홀드아웃 정답 |
|---|---:|
| 현재 4모델, 기존 가중치 | 959/1,000 |
| 4B 두 모델만 회전 평균, 기존 가중치 유지 | 964/1,000 |
| 4B 두 모델 회전 평균, 네 모델 균등 평균 | 965/1,000 |

우선 **기존 가중치를 유지하는 964/1,000 방식**을 시험한다. 현 방식 대비 5개를 새로 맞히고 잃은 문항은 없어 순증 5개다. 965/1,000 방식은 가중치까지 함께 바뀌므로 별도 후보로 기록한다. 이 차이는 표본 1,000개에서 작아 Public 향상을 보장하지 않는다.

현재 로컬에는 공유 저장소의 홀드아웃 확률 파일이 있지만 두 4B 모델의 학습 어댑터와 기본 가중치는 없다. 팀의 해당 파일을 받아오면 먼저 회전 0의 확률이 저장된 결과와 일치하는지 확인한다. 확보할 수 없으면 공유 저장소 레시피로 재학습한 뒤 동일한 홀드아웃에서 기준을 다시 세운다. 이어 회전 1~3을 테스트 6,714개에 추론하고, 회전마다 원래 보기 순서로 확률을 되돌린 후 평균한다. 중간 확률은 행별로 저장해 재개 가능하게 한다. 기존 `src/score.py --rot` 구현과 저장된 홀드아웃 결과를 기준으로 삼는다.

**채택 조건:** 회전 0 재현, 홀드아웃 ID 정렬 확인, 기존 가중치의 964/1,000 재현, 테스트 6,714행 생성·검증. Public 제출은 한 번만 하고 현재 0.96187과 비교한다. 예상 추가 추론은 공유 저장소 기록 기준 약 4.8시간이며 모델 파일 확보 시간은 별도다.

## 2. 남은 오답을 이미지 문제와 선택 문제로 분리

현재 41개 오답을 이미지, 질문, 네 모델 확률과 함께 검토한다. `숫자·가격·전화번호`, `작은 글자·다국어`, `대상 위치·관계`, `복수 표기·보기 오타·라벨 의심`으로 기록한다. 현재 후보가 틀렸지만 구성 모델 하나가 맞힌 30개는 **모델 선택/확률 결합** 문제다. 네 모델 모두 틀린 11개는 **이미지 판독 또는 정답표** 문제로 따로 본다. test 이미지는 정답을 모르는 상태에서 같은 알고리즘으로만 처리한다.

## 3. 로컬 OCR + 질문 대상 영역 실험

숫자·작은 글씨 유형에서만 로컬 OCR로 읽은 글자와 위치를 추출한다. 원본 전체를 강제로 확대하지 않고, 질문과 선택지에 연관된 글자 주변을 자른 이미지와 OCR 텍스트를 모델에 입력한다. 현재의 고정 좌우상하 크롭보다 대상 연결을 잘할 수 있는지 확인한다. OCR이 틀린 경우가 있으므로 기존 모델 확률이 낮은 문항만 재추론하고, 적용 기준은 학습용 데이터에서 결정한다.

홀드아웃 오답만 보고 영역이나 프롬프트를 직접 맞추지 않는다. train-fit에서 별도 개발 분할을 만들고 OCR 인식률과 정답 순증을 먼저 측정한다. 고정 홀드아웃에서는 현 최고 후보와 짝비교해 새로 맞힌 수와 잃은 수를 기록한다. 순증이 없으면 test 추론을 하지 않는다.

## 4. 새로운 학습은 오답 유형에 집중

회전·OCR 뒤에도 남는 오답 유형을 기준으로, train-fit의 해당 유형을 더 자주 보여주는 LoRA 실험을 한다. 정답 문자는 기존처럼 한 토큰만 학습하고, 질문/보기 셔플과 1 epoch 기준은 유지한다. 이미지 영역 선택을 학습에 넣는 경우 정답 정보로 crop 위치를 정하지 않는다. 별도 개발 분할에서 개선을 확인한 설정만 전체 train-fit에 적용한다.

새 모델은 단독 정확도와 현재 앙상블의 오답 복구 수를 함께 측정한다. 새 모델이 특정 유형에서만 유리하면 그 유형을 판별하는 규칙은 train-fit 개발 분할에서 고정하고 홀드아웃에서는 한 번만 평가한다. Public 제출은 고정 홀드아웃 순증과 전체 6,714행 형식 검사를 통과한 후보로 제한한다.

## 결과물과 중단 기준

각 실험은 홀드아웃·테스트 확률, 비교표(복구/손실), 재현 명령, 6,714행 제출 CSV를 함께 남긴다. 최고 Public 0.96187 파일은 보존한다. 1단계의 가중치가 없거나 회전 0을 재현하지 못하면 4B 테스트 추론을 시작하지 않고 8B 자체의 회전 실험으로 전환한다. 2~4단계는 앞 단계의 오답을 다시 분석해 대상 유형을 갱신한다.
